# DSS de ventas Walmart

Dashboard web (Sistema de Soporte a Decisiones) sobre las ventas semanales de 45 tiendas Walmart, feb-2010 a oct-2012.

- **Sitio publicado:** https://USUARIO.github.io/dss-ventas-walmart/
- **Datos:** Walmart Sales (Kaggle). Procesados en `data.json`.
- **Tecnologías:** HTML, CSS, JavaScript y Chart.js. Se publica con GitHub Pages.
